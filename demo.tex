\section{Abstract}
Il progetto definisce un'architettura di database semplificata per la gestione di un simulatore
di corse automobilistiche ispirato alla Formula 1. L'obiettivo è fornire una struttura
essenziale e scalabile per tracciare scuderie, piloti, vetture e i risultati delle competizioni.
\\Il sistema modella la gestione del personale attraverso persone (piloti e tecnici) e i loro contratti
con le scuderie nel tempo.
\\La parte sportiva gestisce Campionati, Sessioni e Circuiti, registrando i risultati finali
di ogni pilota in ogni sessione. Ogni campionato adotta una specifica versione del Regolamento
tecnico FIA, che definisce i vincoli a cui le vetture devono conformarsi durante la stagione.

\section{Analisi dei Requisiti}

Questa base di dati serve a gestire le informazioni relative a un simulatore di corse
automobilistiche ispirato alla Formula 1, in cui il giocatore gestisce una scuderia,
sviluppa la vettura e partecipa a campionati.

\invio
\textbf{Persona}.
Le persone sono tutte le figure umane che operano all'interno di una scuderia.
Sono identificate da un codice fiscale e descritte dalle seguenti informazioni:
\begin{itemize}
    \item Il \textbf{Codice Fiscale} che identifica univocamente la persona.
    \item Il \textbf{Nome} e il \textbf{Cognome}.
    \item La \textbf{Nazionalità}.
\end{itemize}
Le persone si dividono in Piloti e Tecnici.

\invio
\textbf{Pilota}.
Oltre alle informazioni generali delle persone, un pilota è caratterizzato da:
\begin{itemize}
    \item Lo \textbf{Stile di Guida}, ovvero l'approccio alla guida
          (Aggressivo, Conservativo, Bilanciato).
    \item Il livello di \textbf{Esperienza}, che influenza le prestazioni in gara.
\end{itemize}

\textbf{Tecnico}.
Oltre alle informazioni generali delle persone, un tecnico è caratterizzato da:
\begin{itemize}
    \item La \textbf{Specializzazione} tecnica (Aerodinamica, Motore, Gomme).
\end{itemize}

\textbf{Scuderia}.
La scuderia rappresenta il team gestito dal giocatore. È descritta da:
\begin{itemize}
    \item Il \textbf{Nome} che la identifica univocamente.
    \item La \textbf{Sede} geografica del team.
\end{itemize}
Una persona è legata a una scuderia tramite un \textbf{Contratto}, descritto da:
\begin{itemize}
    \item L'\textbf{Anno di Inizio} e l'\textbf{Anno di Fine} del contratto.
    \item Il \textbf{Stipendio} percepito.
\end{itemize}

% pagina 4
\textbf{Vettura}.
Ogni scuderia sviluppa una o più vetture nel corso delle stagioni. Una vettura
è descritta da:
\begin{itemize}
    \item Il \textbf{Modello} della vettura (es. SF-24, W15).
    \item Il \textbf{Peso} che usa la macchina.
    \item L'\textbf{Accelerazione} della macchina.
    \item La \textbf{Velocità} massima che il veicolo può raggiungere.
\end{itemize}

\textbf{Circuito}.
I circuiti sono le piste su cui si svolgono le sessioni di gara. Sono descritti da:
\begin{itemize}
    \item Il \textbf{Nome} che lo identifica univocamente.
    \item Il \textbf{Paese} in cui si trova.
    \item La \textbf{Lunghezza} in chilometri.
    \item Il \textbf{Numero di Curve}.
    \item Il \textbf{Tipo} di circuito (Cittadino, Permanente, Misto).
\end{itemize}

\textbf{Regolamento}.
Ogni campionato è regolato da una versione specifica del regolamento tecnico FIA.
Il regolamento è descritto da:
\begin{itemize}
    \item La \textbf{Versione} che lo identifica univocamente.
    \item Il \textbf{Peso Massimo} e il \textbf{Peso Minimo} consentiti per le vetture.
    \item L'abilitazione del \textbf{DRS}, ovvero se il sistema di riduzione della
          resistenza aerodinamica è consentito.
    \item La \textbf{Data di Rilascio}, ovvero quando la FIA ha pubblicato
          questa versione.
\end{itemize}

\textbf{Campionato}.
Il campionato rappresenta una stagione di gare. È identificato univocamente dalla
combinazione di \textbf{Nome} e \textbf{Anno}, ed è descritto da:
\begin{itemize}
    \item Il \textbf{Nome} del campionato (Mondiale Costruttori, Mondiale Piloti).
    \item L'\textbf{Anno} di svolgimento.
    \item Il \textbf{Budget Cap}, ovvero il limite di spesa imposto dalla FIA
          per quella stagione, uguale per tutte le scuderie.
    \item Il \textbf{Montepremi} totale distribuito alle scuderie a fine stagione.
\end{itemize}

% pagina 5
\textbf{Gara}.
Una sessione rappresenta una singola attività di gara su un circuito. È descritta da:
\begin{itemize}
    \item La \textbf{Data} in cui avviene la corsa.
    \item Le \textbf{Condizioni Meteo} (Soleggiato, Nuvoloso, Pioggia).
    \item La \textbf{Temperatura} dell'asfalto.
\end{itemize}
I piloti partecipano alle sessioni al volante di una vettura. Ogni giro percorso
da un pilota durante una sessione viene tracciato come \textbf{Giro}, descritto da:
\begin{itemize}
    \item Il \textbf{Numero del Giro}.
    \item I tempi parziali \textbf{Settore 1}, \textbf{Settore 2} e \textbf{Settore 3}.
    \item La \textbf{Gomma Utilizzata} in quel giro (Soft, Medium, Hard, Intermedie, Wet).
\end{itemize}
Al termine di ogni sessione viene registrato il \textbf{Risultato} di ogni pilota,
descritto da:
\begin{itemize}
    \item La \textbf{Posizione} finale, nulla in caso di ritiro.
    \item I \textbf{Punti} ottenuti, nulli in caso di ritiro.
    \item L'eventuale \textbf{Causa della Squalifica}
          (Incidente, Guasto meccanico, Squalifica, Abbandono).
\end{itemize}

\textbf{Partecipazione}. È identificato univocamente dalla
combinazione di \textbf{Pilota} e \textbf{Gara}, ed è descritto da:
\begin{itemize}
    \item La \textbf{Posizione di Partenza} del pilota in una determinata gara.
\end{itemize}

\section{Progettazione Concettuale}
\subsection{Lista Entità}

Il database è formato dalle seguenti entità:
 
\begin{itemize}
    \item \textbf{Persona}
    \begin{itemize}
        \item \underline{CodiceFiscale: varchar}
        \item Nome: varchar
        \item Cognome: varchar
        \item Nazionalità: varchar
    \end{itemize}
 
    \item \textbf{Pilota} (figlia di Persona)
    \begin{itemize}
        \item StileGuida: enum (Aggressivo, Conservativo, Bilanciato)
        \item Esperienza: int
        \begin{itemize}
            \item Esperienza $\ge$ 0
        \end{itemize}
    \end{itemize}
 
    \item \textbf{Tecnico} (figlia di Persona)
    \begin{itemize}
        \item Specializzazione: enum (Aerodinamica, Motore, Gomme)
    \end{itemize}
 
    \item \textbf{Scuderia}
    \begin{itemize}
        \item \underline{Nome: varchar}
        \item Sede: varchar
    \end{itemize}
 
    \item \textbf{Vettura}
    \begin{itemize}
        \item \underline{Modello: varchar}
        \item Peso: float
        \begin{itemize}
            \item Peso $>$ 0
        \end{itemize}
        \item Accelerazione: float
        \begin{itemize}
            \item Accelerazione $>$ 0
        \end{itemize}
    \end{itemize}
 
    \item \textbf{Circuito}
    \begin{itemize}
        \item \underline{Nome: varchar}
        \item Paese: varchar
        \item Lunghezza: float
        \begin{itemize}
            \item Lunghezza $>$ 0
        \end{itemize}
        \item NumeroCurve: int
        \begin{itemize}
            \item NumeroCurve $\ge$ 1
        \end{itemize}
        \item Tipo: enum (Cittadino, Permanente, Misto)
    \end{itemize}
 
    \item \textbf{Regolamento}
    \begin{itemize}
        \item \underline{Versione: float}
        \item PesoMassimo: float
        \item PesoMinimo: float
        \begin{itemize}
            \item PesoMassimo $>$ 0 e PesoMinimo $>$ 0
            \item PesoMassimo $>$ PesoMinimo
        \end{itemize}
        \item DRSConsentito: boolean
        \item DataRilascio: date
    \end{itemize}
 
    \item \textbf{Campionato}
    \begin{itemize}
        \item \underline{Nome: varchar (Composta con Anno)}
        \item \underline{Anno: int (Composta con Nome)}
        \begin{itemize}
            \item Anno $\ge$ 1950
        \end{itemize}
        \item BudgetCap: int
        \begin{itemize}
            \item BudgetCap $\ge$ 0
        \end{itemize}
        \item Montepremi: int
        \begin{itemize}
            \item Montepremi $\ge$ 0
        \end{itemize}
    \end{itemize}
 
    \item \textbf{Gara}
    \begin{itemize}
        \item \underline{IdGara: int}
        \item Data: date
        \item CondizioniMeteo: enum (Soleggiato, Nuvoloso, Pioggia)
        \item TemperaturaAsfalto: float
    \end{itemize}

    \item \textbf{Partecipazione}
    \begin{itemize}
            \item PosPartenza: int
            \begin{itemize}
            \item PosPartenza $\ge$ 1
        \end{itemize}
    \end{itemize}
 
\end{itemize}

\subsection{Lista Relazioni}
Il database è formato dalle seguenti relazioni:

\begin{itemize}

    \item \textbf{Persona-Scuderia}: Contratto (1:N)
    \begin{itemize}
        \item Una persona firma contratti con una sola scuderia nel tempo
        \item Una scuderia ha più persone sotto contratto
        \begin{itemize}
            \item AnnoInizio: int
            \item AnnoFine: int
            \begin{itemize}
                \item AnnoFine $\ge$ AnnoInizio
            \end{itemize}
            \item Stipendio: int
            \begin{itemize}
                \item Stipendio $\ge$ 0
            \end{itemize}
        \end{itemize}
    \end{itemize}

    \item \textbf{Scuderia-Vettura}: Appartiene (1:N)
    \begin{itemize}
        \item Una scuderia possiede più vetture nel corso delle stagioni
        \item Una vettura appartiene a una sola scuderia
    \end{itemize}

    \item \textbf{Campionato-Regolamento}: Adozione (1:1)
    \begin{itemize}
        \item Un campionato adotta una sola versione del regolamento
        \item Una versione del regolamento è adottata da un solo campionato
    \end{itemize}

    \item \textbf{Campionato-Gara}: Inclusione (1:N)
    \begin{itemize}
        \item Un campionato include più gare nel corso della stagione
        \item Una gara appartiene a un solo campionato
    \end{itemize}

    \item \textbf{Circuito-Gara}: Svolgimento (1:N)
    \begin{itemize}
        \item Un circuito ospita lo svolgimento di più gare nel tempo
        \item Una gara si svolge su un solo circuito
    \end{itemize}

    \item \textbf{Pilota-Partecipazione}: Iscrizione (1:N)
    \begin{itemize}
        \item Un pilota può iscriversi a più partecipazioni (gare) nel tempo
        \item Una specifica partecipazione fa riferimento a un solo pilota iscritto
    \end{itemize}

    \item \textbf{Vettura-Partecipazione}: Utilizzo (1:N)
    \begin{itemize}
        \item Una vettura può essere utilizzata per più partecipazioni
        \item Una specifica partecipazione prevede l'utilizzo di una sola vettura
    \end{itemize}

    \item \textbf{Gara-Partecipazione}: Riferimento (1:N)
    \begin{itemize}
        \item Una gara ha come riferimento più partecipazioni di piloti e vetture
        \item Una specifica partecipazione si riferisce a una sola gara
    \end{itemize}

    \item \textbf{Pilota-Gara}: Giro (N:M)
    \begin{itemize}
        \item Un pilota percorre più giri durante una gara
        \item Una gara registra i giri di tutti i piloti partecipanti
        \begin{itemize}
            \item NumeroGiro: int
            \begin{itemize}
                \item NumeroGiro $\ge$ 1
            \end{itemize}
            \item TempoGiro: time
            \item Settore1: time
            \item Settore2: time
            \item Settore3: time
            \item GommaUsata: enum (Soft, Medium, Hard, Intermedie, Wet)
        \end{itemize}
    \end{itemize}

    \item \textbf{Pilota-Gara}: Risultato (N:M)
    \begin{itemize}
        \item Un pilota ottiene un risultato finale per ogni gara a cui partecipa
        \item Una gara registra il risultato finale di ogni pilota partecipante
        \begin{itemize}
            \item Posizione: int
            \begin{itemize}
                \item Posizione $\ge$ 1
                \item Posizione ammette valore nullo in caso di ritiro
            \end{itemize}
            \item Punti: int
            \begin{itemize}
                \item Punti $\ge$ 0
                \item Punti ammette valore nullo in caso di ritiro
            \end{itemize}
            \item CausaSqualifica: enum (Incidente, Guasto meccanico, Squalifica, Abbandono)
            \begin{itemize}
                \item CausaSqualifica ammette valore nullo
            \end{itemize}
        \end{itemize}
    \end{itemize}
    \item \textbf{Tecnico-Partecipazione}: Controllo (1:N)
    \begin{itemize}
       \item Un tecnico può controllare o supervisionare più partecipazioni nel tempo (più combinazioni di vetture e gare)
        \item Una specifica partecipazione (ovvero l'impiego di una determinata vettura in una determinata gara) viene controllata da un solo tecnico\begin{itemize}
            \item Note: varchar
            \begin{itemize}
                \item Note ammette valore nullo
            \end{itemize}
        \end{itemize}
    \end{itemize}

\end{itemize}

\subsection{Schema Relazionale}
Lo schema logico è rappresentato qui sotto, dove l’asterisco dopo il nome degli attributi indica quelli che ammettono valori nulli. 
\begin{itemize}
    \item Persona (\underline{CF}, Nome, Cognome, Nazionalita)
    
    \item Pilota (\underline{Persona}, Esperienza, StileGuida)
    \begin{itemize}
        \item Pilota.Persona $\to$ Persona.CF
    \end{itemize}

    \item Tecnico (\underline{Persona}, Specializzazione)
    \begin{itemize}
        \item Tecnico.Persona $\to$ Persona.CF 
    \end{itemize}

    \item Contratto (\underline{Persona, Scuderia}, Stipendio, AnnoInizio, AnnoFine)
    \begin{itemize}
        \item Contratto.Persona $\to$ Persona.CF
        \item Contratto.Scuderia $\to$ Scuderia.Nome 
    \end{itemize}

    \item Scuderia (\underline{Nome}, Sede)
    
    \item Vettura (\underline{Modello}, Accelerazione, Velocità, Peso, Scuderia)
    \begin{itemize}
        \item Vettura.Scuderia $\to$ Scuderia.Nome
    \end{itemize}

    \item Regolamento (\underline{Versione}, PesoMin, PesoMax, DataRilascio, DRSConsentito)
    
    \item Campionato (\underline{Nome, Anno}, BudgetCap, Montepremi, Regolamento) 
    \begin{itemize}
        \item Campionato.Regolamento $\to$ Regolamento.Versione
    \end{itemize}

    \item Circuito (\underline{Nome}, Paese, Lunghezza, N\_Curve, Tipo)
    
    \item Gara (\underline{Circuito, Data}, Temperatura, Meteo, CampionatoNome, CampionatoAnno)
    \begin{itemize}
        \item Gara.Circuito $\to$ Circuito.Nome
        \item Gara.CampionatoNome $\to$ Campionato.Nome
        \item Gara.CampionatoAnno $\to$ Campionato.Anno
    \end{itemize}

    \item Giro (\underline{Pilota, GaraCircuito, GaraData}, Settore1, Settore2, Settore3, GommaUsata, NGiro)
    \begin{itemize}
        \item Giro.Pilota $\to$ Pilota.Persona
        \item Giro.GaraData $\to$ Gara.Data
        \item Giro.GaraCircuito $\to$ Gara.Circuito
    \end{itemize}

    \item Risultato (\underline{Pilota, GaraCircuito, GaraData}, Posizione, Punti, CausaSqualifica)
    \begin{itemize}
        \item Risultato.Pilota $\to$ Pilota.Persona
        \item Risultato.GaraData $\to$ Gara.Data
        \item Risultato.GaraCircuito $\to$ Gara.Circuito
    \end{itemize}

    \item Partecipazione (\underline{Pilota, GaraCircuito, GaraData}, Vettura, Tecnico, PosPartenza, Note*)
    \begin{itemize}
        \item Partecipazione.Pilota $\to$ Pilota.Persona
        \item Partecipazione.GaraData $\to$ Gara.Data
        \item Partecipazione.GaraCircuito $\to$ Gara.Circuito
        \item Partecipazione.Vettura $\to$ Vettura.Modello
    \end{itemize}
\end{itemize}
